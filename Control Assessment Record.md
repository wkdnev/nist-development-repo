# \<System Name\> Control Assessment Record

## 1 How to use this document

This document is the record of the Level 1 self-assessment of \<System Name\> against CSS. It has one chapter for each of the 19 control families assessed, in CSS order, and each chapter gives a finding for every determination statement. The Level 2 team re-determines every statement from this record, and \<Security Assessment Report\> brings the Level 2 results together. Every authorisation rests on the Level 2 results, not on this record alone (\<Assessment, Authorization, and Monitoring Management\>, section 3.3).

Level 1 is a self-assessment and is not independent. Each chapter holds its own assessment plan, and the authorising official approves each plan before the assessment starts.

- **Chapters.** Each chapter is named by its family code. Its sections carry the code, so PS.3 is section 3 of the Personnel Security chapter, and its tables are numbered Table PS-1, Table PS-2 and so on.
- **Citing.** Cite a chapter as \<Control Assessment Record\> (PS), a section as \<Control Assessment Record\>, section PS.3, and a table as \<Control Assessment Record\>, Table PS-1.
- **Versions.** The document has one version. A change to any chapter is a new version of the document.
- **Filling it in.** Replace each placeholder in square brackets, such as \[Result\], \[Finding\] and \[Basis\], with what the assessment found. Keep the determination statements and the plan as they stand unless the plan is changed and approved again.

### 1.1 Findings

Findings follow CSS. Each determination statement gets one of these.

**Table 1: Finding codes**

| Code | Meaning |
| --- | --- |
| S | Satisfied |
| N/A | Not applicable. It is counted in the chapter's statements, but not as satisfied |
| O-D | Other than satisfied: a decision or approval is outstanding, or the control has not yet started to operate |
| O-G | Other than satisfied: a gap in the system |
| O-E | Other than satisfied: evidence from the VMs or \<Organisation\> is not available |

A finding does not by itself require a fix: each non-compliance is rated and decided in \<Risk List\>, and only those to be remediated go to \<Plan of Action and Milestones\>. An interview answer changes a finding only when the records it describes are seen. A statement found not applicable is counted in its chapter's statements but not as satisfied, and rests on the tailoring decision in \<Tailoring Register\>, which the independent assessor may test.
